# 생각이 만나는 미술관

창의적 사고 촉진을 위한 디지털 미술관 활용 미술교육 웹앱입니다.
별도 설치·빌드 없이 GitHub Pages에서 실행됩니다.

## GitHub Pages에 올리기

1. ZIP 파일을 컴퓨터에서 압축 해제합니다.
2. GitHub에서 사용할 저장소를 엽니다. 새 저장소라면 예를 들어 `museum-studio`로 만듭니다.
3. **Add file → Upload files**를 선택합니다.
4. 압축 해제한 폴더 안의 `index.html`, `app.js`, `museum.css`, `README.md`를 모두 올립니다. 폴더 전체나 ZIP 자체를 올리지 말고, 파일을 저장소 맨 위에 배치하세요. `.nojekyll`이 보이면 함께 올려도 됩니다. 필수 파일은 아닙니다.
5. **Commit changes**로 저장합니다.
6. 저장소 **Settings → Pages**로 이동합니다.
7. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
8. **Branch**에서 `main`, 폴더에서 `/(root)`를 선택하고 **Save**를 누릅니다. 기본 브랜치 이름이 다르면 파일을 올린 브랜치를 선택합니다.
9. 배포가 끝나면 Pages 화면에 표시된 사이트 주소를 엽니다. 반영에는 몇 분 걸릴 수 있습니다.

계정이 `hhy7191`, 저장소가 `museum-studio`인 경우 예상 주소는 다음과 같습니다.
https://hhy7191.github.io/museum-studio/
실제 주소는 GitHub Pages 설정 화면에서 확인하세요.

## 올바른 저장소 구조

- index.html — 첫 화면
- app.js — 활동 27단계, 그림판, 소리 도구, 기록, AI 질문 준비
- museum.css — 흰 배경과 검정 글씨 중심의 미술관 스타일
- README.md — 설치 및 사용 안내
- .nojekyll — 정적 파일 서비스용 선택 파일

`index.html`이 폴더 안으로 한 단계 더 들어가 있으면 첫 화면이 열리지 않을 수 있습니다. 파일 이름의 대소문자도 그대로 유지하세요.

## 학습 기능

- 시각적 연결: 작품과 경험 연결, 의미 문장과 이미지 재구성
- 감정 캐릭터 표현: 드로잉·픽셀, 메시지 표현, PNG 저장
- 공감각 하모니: 시각 악보, 8칸 음 조합, 빠르기·음색 실험
- 각 활동 9단계, 탐색–해석–표현·공유 구조
- 현재 브라우저에 자동 저장, JSON 기록 내보내기·불러오기, 인쇄·PDF 저장

## AI 활용 범위

이 버전은 학생의 기록을 토대로 AI 질문을 준비하고, 교사의 안내에 따라 ChatGPT 새 창에서 질문을 붙여 넣는 방식입니다. 답변을 웹앱에 붙여 넣고 학생이 선택·수정한 생각을 기록합니다.
웹앱 내부의 실시간 AI 답변·AI 이미지 생성·AI 음악 생성 기능은 연결되어 있지 않습니다. 8칸 소리 도구는 학생이 직접 정한 음을 재생합니다.
GitHub Pages는 정적 호스팅이므로 내부 AI 응답을 구현하려면 별도의 서버와 API 연결이 필요합니다. API 키를 HTML·JavaScript 또는 GitHub 저장소에 넣지 마세요.

## 학생 기록과 공개 범위

GitHub Pages에 배포하면 사이트 주소를 아는 사람이 접속할 수 있습니다. 이 ZIP에는 학생 응답·그림 등 실제 사용자 기록이 포함되지 않습니다.
학생의 기록은 각 기기의 해당 브라우저에만 저장됩니다. 기기·브라우저·사이트 주소가 달라지면 자동으로 옮겨지지 않습니다. 이전 사이트 기록을 옮기려면 이전 사이트에서 JSON 기록을 저장하고 새 사이트에서 불러오세요.
실제 학생 기록 파일을 GitHub에 업로드하지 마세요. 교사의 학급 기록 수집이나 온라인 공동 갤러리는 포함되지 않습니다.

## 수정하기

활동 문구와 동작은 `app.js`, 첫 화면은 `index.html`, 디자인은 `museum.css`에서 수정합니다. 변경한 파일을 저장소에 다시 올리면 Pages에 반영됩니다.
